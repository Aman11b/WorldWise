# 🌍 WorldWise – React Travel Tracking App

A React application built as a deep learning project to understand routing, state management, performance optimization, and modern React architecture.

Users can interact with maps, add cities they've visited, manage location data, and experience protected routes with authentication.

---

## 🚀 Features

### Navigation & Routing

- Nested routes and index routes
- Dynamic routes with URL parameters
- Query string handling
- Programmatic navigation using `useNavigate`
- Protected routes using authentication
- Navigation using `Link` and `NavLink`

### Map & Location Features

- Interactive maps using Leaflet
- Display city markers
- Geolocation support
- Fetching geographic data
- Dynamic map positioning

### State Management

- `useReducer` for complex state logic
- Context API for global state management
- Managing local vs global state
- URL as UI state management

### Authentication

- Fake authentication implementation
- Login flow
- Protected route handling

### Performance Optimization

- `memo`
- `useMemo`
- `useCallback`
- Context re-render optimization
- Code splitting and lazy loading
- Bundle size optimization
